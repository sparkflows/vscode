# Configuration Nodes

## DAG Configuration
- **Add DAG Arguments** `10-Configuration/AddDAGArguments.json` — This node is used to add DAG arguments.
- **Add DAG Variables** `10-Configuration/AddDAGVariables.json` — This node executes Python code to add DAG variables using the Python operator
- **Add YAML Configuration** `10-Configuration/AddYamlConfiguration.json` — Add YAML Configuration files. Can add multiple YAML configuration files.
