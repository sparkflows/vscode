# Code Nodes

## Execution
- **Bash Operator** `02-Code/bashOperator.json` — This node executes a Bash script, command or set of commands.
- **Python Operator** `02-Code/pythonOperator.json` — This node executes Python code using the Python operator

## Branch
- **Branch Python Operator** `01-Branch/branchPythonOperator.json` — This node executes a certain path based on return value from the previous task.
